## GeoHarvest 0.3.4 beta: Resume is back after opening the app

A small fix for 0.3.3. Nothing else changed.

### Fixed

- **"Something went wrong: no attribute 'step'" when GeoHarvest opens.** If you had a paused,
  stopped or waiting search that visits websites, 0.3.3 showed this message, left the Leads
  tile empty and did not show the Resume button. A search waiting for Google also did not
  start again by itself. Your searches and leads were never affected: open 0.3.4 and Resume
  is there again.

### Paste-ready release description

> GeoHarvest 0.3.4 fixes one bug in 0.3.3: opening the app with a paused, stopped or waiting
> search could show "Something went wrong: no attribute 'step'", with no Resume button and an
> empty Leads tile. Nothing was lost, and Resume is back in this version. Installed copies
> offer the update by themselves. For a new install, download the zip below, extract it, and
> run GeoHarvest-Setup.exe.
