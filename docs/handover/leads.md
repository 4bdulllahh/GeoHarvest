# Leads page and exports

The Leads page, its Show and Sort menus, filters, columns and every export. Code: `app/ui/pages/leads.py`, `app/ui/widgets/leads_model.py`, `app/core/exporter.py`. Decisions already made: don't re-ask them. Each row says what was chosen and why.

| Topic | Decision |
|---|---|
| Leads page | Opens on the newest search, and switches to a search when it starts. Double-click opens `LeadDialog` (every filled field, links, Copy all, Open in Google Maps). Delete key, right-click or "Delete selected" removes leads (`searches.delete_leads`): from the selected search, or from every search when "All searches" is picked. Past searches > **Load** selects the search on the Leads page and shows a toast without leaving the page |
| Leads filters (0.3) | `widgets/leads_model`: `SORTS`/`SORT_MENU` (a Sort entry is a column + order; "rank" is no column, the order the search ranked them; a heading click updates the button via `_sorted_by_heading`; remembered in `leads_sort`), `SHOWS`/`SHOW_MENU` (one rule per Show entry), plus rating/reviews `RangeSlider`s (closing the panel lets go of them) and `widgets/date_range.DateRange` (from HomingPigeon) on the found date. Every lead gets `found` (the leads row's `created` day) when loaded, and `exported` (via `search.mark_exported`, all searches that have it, SQLite `json_set`) after an export or Copy for Google Sheets; both are in `places.RECORD_FIELDS`, shown under Leads > Columns, not on New search. Export for HomingPigeon is a CRM entry with one row per email (`exporter.ONE_ROW_PER_EMAIL`), headers Email/Company/Contact person that its import detects; the rest become its merge variables. Copy emails/phones: one per line, each once, international phone first. Date formats are in `prefs` (same as HomingPigeon; the Settings choice comes in 7) |
| Columns after a search | Leads page "Columns..." opens `ColumnsDialog` (select buttons grouped like New search, `places.FIELD_GROUPS`; every FIELDS key in exactly one group, tested). Saves to the search's `fields` (`searches.set_fields`) or, for All searches, setting `all_searches_fields` |
| Exports (0.2.1) | Leads page "More exports": CSV, CSV for HubSpot / Pipedrive / Zoho CRM / Salesforce (`exporter.CRMS`: each CRM's company/account column names), "Copy for Google Sheets" (tab-separated text on the clipboard + opens sheets.new; values starting with = + - @ get a leading ' so Sheets keeps them as text). A direct Google Sheets upload was rejected: it needs OAuth and a Google Cloud project |
